= gatling-build-plugin

image::https://github.com/gatling/gatling-build-plugin/actions/workflows/build.yml/badge.svg?branch=main[build]

SBT plugins to share common settings across Gatling's projects' builds.

Supports both sbt 1.x and sbt 2.x.

== GatlingOssPlugin

Common settings for OSS project in `io.gatling` group.

=== How to use

.build.sbt
[source,sbt]
----
inScope(Global) {
  Seq(
    githubPath := "gatling/my-awesome-project", // <1>
    gatlingDevelopers := Seq( // <2>
      GatlingDeveloper("jsmith@gatling.io", "John Smith", isGatlingCorp = false)
    )
  )
}

lazy val root = (project in file("."))
  .enablePlugins(GatlingOssPlugin)
  .settings(
    name := "my-awesome-project" // <3>
  )
----

<1> github path for `pom.xml` SCM info
<2> developers and contributors for `pom.xml` developers
<3> artifact name

=== Versioning

The version is computed from git tags with link:https://github.com/sbt/sbt-dynver[sbt-dynver] (`v` prefixed tags, e.g. `v1.2.3`), so no `version.sbt` is needed.

=== New commands

==== sbt "gatlingBumpVersion <bump-type>"

Computes the next version from the current git tag.
`gatlingWriteBumpVersion <bump-type>` does the same and writes the result in `target/.../gatlingNextVersion`.

bump-type:

 - `patch`, `minor`, `calver`
 - `patch-milestone`, `minor-milestone`, `calver-milestone`

=== Releasing

Releases are driven by tags:

 . compute the next version with `gatlingWriteBumpVersion` and push the matching `v<version>` git tag
 . on tag push, CI runs `sbt "release with-defaults"` to build and publish

=== Publishing to a staging repository

By default, releases are published to Sonatype Central.
To publish them (signed, for every `crossScalaVersions`) to a staging repository instead:

[source,shell]
----
sbt 'set every gatlingPublishToStaging := true ; release with-defaults'
# or, publish only
sbt 'set every gatlingPublishToStaging := true ; +publishSigned'
----

The staging repository is not defined by this plugin, it must be provided by the environment, e.g. in a global `.sbt` file (`~/.config/sbt/2/`):

[source,sbt]
----
// Same name and type as the key declared by gatling-build-plugin
val gatlingStagingRepository = settingKey[Option[Resolver]]("Repository used when gatlingPublishToStaging is true")

Global / gatlingStagingRepository := Some("My staging" at "https://my-repository/maven/staging")

credentials += Credentials("<realm>", "my-repository", "<user>", "<password>")
----
